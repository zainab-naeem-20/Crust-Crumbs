## 📖 About The Project

**Crust & Crumbs** is a sleek and interactive web application designed for a premium bakery and custom cake shop. It offers customers a delightful browsing experience to explore fresh artisanal bakes, view specialized menus, and place custom cake inquiries easily.

---

## ✨ Features

- 🎨 **Modern & Aesthetic UI:** Clean visual design showcasing products with high-appeal aesthetics.
- 📱 **Fully Responsive Layout:** Flawless experience across mobile, tablet, and desktop devices.
- 🎂 **Interactive Cake Menu:** Filterable categories for cakes, pastries, and artisanal treats.
- 💬 **Custom Order Inquiry:** Easy user journey for placing customized cake requests.
- ⚡ **Fast & Lightweight:** Built using modern utility-first styling with Tailwind CSS for optimal performance.
